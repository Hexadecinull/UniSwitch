# UniSwitch documentation

- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — how UniSwitch converts code under the hood, and what its real limits are.

## For contributors

- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — how to propose a change, add a language plugin, and get a pull request reviewed.
- [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) — expected behavior in the project's spaces.

- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — the technical design, again, because contributors need it too.

- [`DEPLOY.md`](./DEPLOY.md) — general instructions for self-hosting UniSwitch's web app on your own server.

## Policies
